# v1.7.26 — Candidata
Comparación administrativa de dos cuatrimestres distintos, activos o inactivos. Resumen de asesorías, alumnos únicos, minutos y materias; desglose por materia y motivo. Diferencia = comparado − base; porcentaje = diferencia/base × 100; base cero = N/D. No se normalizan periodos parciales. Se excluyen anulaciones. Cálculo local sobre datos administrativos cargados; sin exportación específica. No cambia backend ni SQL. Requiere migraciones 001–008 y TLS de versiones anteriores. npm test: 19 scripts y tres verificaciones de sintaxis aprobados; navegador y PostgreSQL real pendientes.
